REST Mobility Service (Spring Boot 3.0.2 + H2)
Endpoints:
- GET /mobility/lines
- GET /mobility/lines/{id}
- GET /mobility/lines/code/{lineCode}
- POST /mobility/lines
- PUT /mobility/lines/{id}
- DELETE /mobility/lines/{id}
- GET /mobility/schedules/{lineCode}
- GET /mobility/traffic

H2 console available at /h2-console (jdbc url in application.properties)
Default server port: 8081
